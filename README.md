# ✨ Personal CV & Portfolio Website ✨
This is my personal website where I mix my **CV, skills, and portfolio** with a bit of personality.
What started as an assignment quickly grew into something more creative, personal, and fun to build.

🔗 **Live version:**  
https://alinaskultecka.github.io/CV_website/

### ✨ What’s inside?
- **My CV** – education, skills, and experience in one place  
- **Tech & projects** – what I work with and what I enjoy building  
- **Responsive design** – works nicely on both desktop and mobile (in delopment)
- A **“Get to know me” button**

### 🎲 Get to Know Me – Interactive Quiz (innitialy was part of the assignment)
The website features a **“Get to know me”** button that leads to a short **quiz about me**.  
The quiz is designed as a fun and interactive way for visitors to learn more about my background, personality, and interests beyond a traditional CV.

### 🛠️ Tech used
HTML/CSS/VanillaJS

## Purpose & Learning Goals
This project was built to:
- practice core web development fundamentals
- apply structured layout and responsive design principles
- explore simple interactivity using JavaScript
- present my profile in a more engaging format for internship and junior roles

### Status
The project is actively maintained and will continue to evolve as I develop new skills and improve the overall structure and design.
